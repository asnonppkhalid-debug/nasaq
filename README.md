# نَسَق | NASAQ — النسخة 0.3.2

منصة معرفة شخصية: أكاديمية، موسوعة، مكتبة، مراجعة متباعدة، شبكة معرفة، ومساعد.
كل بياناتك تُحفظ في متصفحك فقط (`localStorage`، المفتاح `nasaq:v1`). خذ نسخة احتياطية من «الإعدادات».

## الجديد في 0.2.0: بنّاء المسارات بالذكاء الاصطناعي
في «الأكاديمية» زر «مسار جديد»: تكتب اسم المسار وتفاصيلك (اختياري) وتختار الحجم (مختصر ~8 دروس، متوسط ~12، موسّع ~18)،
فيبني لك مساراً من التأسيس إلى الاحتراف: أربع مراحل، دروس مكتوبة، تمارين، وبطاقات مراجعة.
- **مرحلتان:** مخطط المسار أولاً، ثم طلب مستقل لكل درس (طلبان بالتوازي كحد أقصى).
- **كل درس يُحفظ فور اكتماله.** تقدر توقف البناء، تكمّله لاحقاً (حتى بعد إغلاق الصفحة)، تعيد كتابة درس واحد، أو تحذف المسار.
- **الإيقاف التلقائي:** عند خطأ لا فائدة من تكراره (رفض الإذن، حد الاستخدام) أو بعد 3 إخفاقات متتالية، حتى لا يُصرف استخدامك على الفاضي.
- **التحقق:** كل نص قادم من النموذج يمرّ عبر `PS` (`src/js/24-pathschema.js`): أنواع كتل محدّدة (h/p/note/ul/ol/code)، حدود أطوال،
  إزالة الروابط الداخلية وأحرف تجاوز الاتجاه، ثم يُهرَّب عند العرض. المحتوى المولَّد يظهر بوسم «ذكاء اصطناعي» وتنبيه أنه غير محرَّر.
- المسارات المولَّدة تدخل في البحث والرئيسية والتقدّم والنسخ الاحتياطي والاستيراد.

مصدر الذكاء الاصطناعي بالترتيب (`src/js/23-ai.js`):
1. مزوّد تسجّله أنت: `NASAQ.setAssistantProvider(fn)`
2. قدرة `sample` في منصة العرض (تعمل على حساب Claude الخاص بالمشاهد وبموافقته، وكل طلب يُحسب على استخدامه)
3. لا شيء: نقولها بصدق ولا نمثّل أن هناك ذكاءً اصطناعياً.

## الجديد في 0.3.0
**1) مصادر إضافية بالمسارات:** كل مسار يُبنى معه ٦–١٠ مصادر مقترحة (كتب، فيديوهات/قنوات، دورات، مواقع)، ولكل درس ١–٣ مصادر للتوسّع.
النموذج قد يخطئ بالعناوين، فلا نعرض منه أي رابط أبداً: نحتفظ بالعنوان والمؤلف فقط، والزر يفتح **بحثاً** نبنيه نحن (يوتيوب، أو Google Books، أو الويب).
إذا نسي النموذج حقل المصادر بالمخطط، يُرسل البنّاء تلقائياً طلباً مستقلاً صغيراً يجلبها (فشله لا يوقف بناء الدروس).
يوجد زر «احفظ بمكتبتي» (يُحفظ كعنصر من نوع «مصدر»)، وزر «اقترح مصادر» للمسارات القديمة (طلب واحد).

**2) إعدادات ← نماذج الذكاء الاصطناعي:** أضف نموذجاً واختره كمصدر للبناء وللمساعد:
- **API بمفتاح:** متوافق مع OpenAI (OpenAI، OpenRouter، DeepSeek، Groq، Mistral، أو أي خادم يدعم `chat/completions`)، وAnthropic، وGemini.
- **على جهازك:** Ollama أو LM Studio (عنوان محلي).
- **داخل المتصفح:** WebLLM عبر WebGPU (تحميل مكتبة من jsDelivr ثم النموذج، مرة وحدة).
- زر «اجلب النماذج المتاحة» يجلب أسماء النماذج الفعلية من المزوّد (Gemini وOpenAI-compatible وAnthropic) لتختار منها بدل الكتابة اليدوية، لأن المزوّدين يوقفون أسماء قديمة.
- أخطاء الإدخال تظهر داخل النافذة وتركّز على الخانة الناقصة. وعند ازدحام المزوّد (429/502/503/504) يعيد نَسَق الطلب تلقائياً مرتين (المحلي وزر الاختبار لا يعيدان).
- زر «جرّب الاتصال» قبل الحفظ. المفاتيح تُحفظ في مخزن مستقل `nasaq:ai:v1` **ولا تدخل النسخة الاحتياطية**، ولا تُرسل إلا للعنوان الذي حدّدته.

**تنبيهات مهمة:**
- **داخل منصة العرض (Artifact) الاتصال بأي موقع خارجها محجوب** بسياسة الأمان (`connect-src`)، حتى `localhost`، فالنماذج المضافة لا تعمل هناك (هناك يعمل Claude تلقائياً). تعمل لما تفتح نَسَق كملف مستقل أو على استضافتك.
- بعض المزوّدين يمنعون الاتصال المباشر من المتصفح (CORS). Ollama مثلاً يحتاج `OLLAMA_ORIGINS` ليسمح بعنوان صفحتك، ويُفضّل `OLLAMA_CONTEXT_LENGTH=8192` (الافتراضي 4096).
- المفتاح في المتصفح نصٌّ عادي: استعمل مفتاحاً بحد صرف أو صلاحيات محدودة ولا تضفه على جهاز مشترك.
- النماذج الصغيرة داخل المتصفح ضعيفة بالعربية وبالتزام صيغة JSON؛ نكتب بها دروساً أقصر وطلباً واحداً في الوقت نفسه.

## البناء والاختبار
```
bash build.sh                   # يجمّع src/ في dist/index.html (ملف واحد)
node tests/srs.test.js          # خوارزمية المراجعة
node tests/pathschema.test.js   # تحقق مخطط المسار والمصادر المولَّدة (55 فحصاً)
python3 tests/e2e.py            # المتصفح: 5 مقاسات + رحلة كاملة (يحتاج playwright)
python3 tests/aigen.py          # بنّاء المسارات والمصادر مقابل مزوّد sample وهمي (12 سيناريو)
python3 tests/models.py         # نماذج الإعدادات: خادم وهمي (OpenAI/Anthropic/Gemini) وWebLLM وهمي، CORS ومفاتيح وأخطاء
python3 tests/download.py       # التنزيل عبر قدرة downloads
python3 tests/shots.py          # لقطات الشاشة
python3 tests/ai_shots.py       # لقطات بنّاء المسارات
python3 tests/graph_shot.py     # لقطة الشبكة
```
اختبارا `aigen.py` و`models.py` يستخدمان مزوّدات وهمية؛ لم تُختبر مع خدمات حقيقية (Claude أو أي مزوّد API أو نموذج WebLLM فعلي).

## البنية
- `src/css/` الرموز والتخطيط والمكوّنات والواجهات.
- `src/js/00-util` أدوات، `10–13` المحتوى التجريبي، `20-store` الحفظ، `21-srs` المراجعة،
  `22-app` المسارات والأحداث، `23-ai` طبقة الذكاء الاصطناعي، `24-pathschema` التحقق، `30-ui` مكوّنات مشتركة،
  `60–68` الواجهات، `69-pathgen` بنّاء المسارات والمصادر، `70-aimodels` إعدادات النماذج، `99-main` الإقلاع.
- المحتوى التجريبي (٢٠ موضوعاً و٣ مسارات) غير محرَّر ويظهر بوسم «تجريبي»، ويُطفأ من الإعدادات.

## ربط مساعد برمجياً في الملف المستقل (بديل عن الإعدادات)
```js
NASAQ.setAssistantProvider(async (payload) => 'الرد نصاً')   // payload: { command, question, context, prompt, json }
```
بدون مزوّد ولا `sample` يبقى المساعد عرضاً تجريبياً، وبنّاء المسارات يعرض رسالة صادقة أن الخدمة غير مربوطة.
